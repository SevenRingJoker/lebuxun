# ㉜ 偏差报告前端 UI —— 计划文档

## 现状

- ㉚ 已在收尾发 `ai:planDrift` 事件（DriftReport：三类 items + hasBlock/hasWarn），并把报告文本追加到最终输出（持久化记录）；
- **缺口**：preload 未暴露该事件，渲染进程无法消费；偏差只以 Markdown 文本块呈现，无结构、无状态色、不可折叠。
- vitest 只 include `src/main/**`、`src/shared/**`——可测纯函数须放 `src/shared/`（与 `shared/inline/prompts.ts` 同模式）。

## 目标

实时（事件到达即现）结构化展示偏差卡片：

- 头部：⚠️ + 标题 + 「阻断 N / 警告 M」计数徽标；
- 分组列出：关键产物缺失（红）/ 未完成步骤 / 计划外文件，可折叠；
- **去重**：实时态用卡片替代文本块，历史会话（无事件数据）仍看文本，两者不重复。

## 设计

### 1. 共享纯函数层：`src/shared/drift/driftView.ts`（零依赖，配单测）

```ts
export type UiDriftKind = 'unfinishedTodo' | 'missingArtifact' | 'unexpectedFile'
export interface UiDriftItem { kind: UiDriftKind; severity: 'block' | 'warn'; detail: string }
export interface UiDriftReport { items: UiDriftItem[]; hasBlock: boolean; hasWarn: boolean }

/** 按三类分组，供卡片分区渲染 */
groupDriftItems(report): { missing: UiDriftItem[]; unfinished: UiDriftItem[]; unexpected: UiDriftItem[] }
/** 计数：阻断（missingArtifact）/ 警告（其余） */
driftCounts(report): { block: number; warn: number }
/**
 * 剥离 ㉚ 追加到 assistant 末尾的偏差文本块：
 * 从 '\n\n⚠️ 计划-执行偏差检测：' 到字符串结尾整段删除；
 * 无标记时原样返回（历史/无偏差内容安全）。
 */
stripDriftSection(markdown: string): string
```

### 2. preload + 类型声明

- `src/preload/index.ts`：新增 `onPlanDrift(cb)`，订阅 `ai:planDrift`（沿用 onToolResult 同款 void 订阅风格）；
- `src/renderer/src/api.d.ts`：新增 `onPlanDrift: (cb: (report: UiDriftReport) => void) => void`，UiDrift* 类型在该文件声明（与 UiTodoItem 同处）。

### 3. store 接线：`stores/chat.ts`

- 新增 `liveDrift = ref<UiDriftReport | null>(null)`；
- 订阅 `window.api.ai.onPlanDrift(r => liveDrift.value = r)`；
- `send` 发起时置 null，`clear` / 新建会话 / 切换历史会话时置 null；
- liveDrift 只在当前会话实时有效，不随会话持久化。

### 4. 组件：`components/DriftReportCard.vue`

- 头部一行：⚠️ 图标 + 「计划-执行偏差」+ 计数徽标（阻断=红底，警告=青/琥珀底）+ ▾；
- 默认展开规则：hasBlock 时默认展开（阻断必须可见），仅 warn 默认折叠；
- 展开体三组（空组不渲染），组标题 + 明细行，缺失组红色、warn 组青色系，明细等宽字体、超长省略/换行；
- 样式复用 `cp-glass` + 状态色，与 ToolEventCard 风格统一。

### 5. ChatPanel 渲染

- 最后一条 assistant 消息所在 msg-row，气泡之后插入 `<DriftReportCard v-if="chat.liveDrift" :report="chat.liveDrift" />`；
- 该 assistant 消息 Markdown 渲染前过 `stripDriftSection`（仅 liveDrift 存在时），实时态只显示卡片、不显示重复文本；
- 重载历史会话无 liveDrift → 走原文渲染，偏差文本照常可见。
- 主进程零改动。

### 不做

- 明细行点击跳转文件树/定位（后续可选）；
- 多任务偏差历史累积列表（当前一个会话只产生一次收尾报告）；
- 不改 ㉚ 的事件结构与文本追加逻辑（文本是历史态的唯一载体）。

## 验证

- `src/shared/drift/driftView.test.ts`：分组/计数/默认空态、strip 命中/无标记/不误伤其他 ⚠️ 警告块（npm 警告在偏差块之前，须保留）；
- 三件套：双端 typecheck + 全量 vitest run（计数只增不减）+ build；
- CDP 冒烟：经 Vue devtools hook（`__VUE_DEVTOOLS_GLOBAL_HOOK__` → app → $pinia → chat store）注入合成 liveDrift，验证卡片渲染、计数徽标、分组折叠；临时脚本用完即删。
